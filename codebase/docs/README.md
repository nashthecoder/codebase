# Documentation

This directory contains all documentation for the Hiking Journal project.

Complete interactive guide for setting up your development environment:
- VS Code extensions and configuration
- Claude Code CLI and plugins
- Rails stack (Maquina, 37signals patterns)
- React stack (Next.js, TypeScript, Tailwind)
- Product management workflows

**Quick Access**: Open [setup/index.html](setup/index.html) in your browser for the interactive guide.
