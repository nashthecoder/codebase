Maquina Complete Setup

From rails new to production-ready with maquina.app tools

🏗️
Step 1: Create Rails App
rails new myapp --css tailwind
cd myapp
📦
Step 2: Add Maquina Generators
# Gemfile
gem "maquina_generators", group: :development
gem "maquina_components"

bundle install

🐙 GitHub | 📖 Docs

🚀
Step 3: Run App Generator
rails g maquina:app --auth registration

# Options: --auth none|clave|registration
#          --prefix /admin  (dashboard URL)
#          --port 3000
✅
